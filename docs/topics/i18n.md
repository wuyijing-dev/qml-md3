# Internationalization (i18n)

Md3 user-visible strings should use `qsTr(...)`. Gallery and apps switch language via **`Md3I18n`**.

## Quick start

```qml
import Md3

// After engine load:
Md3I18n.language = "zh_CN"   // or "en"
```

`Md3I18n` installs translators from `:/md3/i18n/md3_<lang>.qm` and calls `QQmlEngine::retranslate()`.

Available codes: `en` (source), `zh_CN`.

## Authoring translations

Source templates:

- `translations/md3_en.ts`
- `translations/md3_zh_CN.ts`

Update from QML/C++:

```powershell
# from repo root — requires Qt Linguist tools on PATH
lupdate src/Md3 -ts translations/md3_zh_CN.ts translations/md3_en.ts
lrelease translations/md3_zh_CN.ts -qm src/Md3/i18n/md3_zh_CN.qm
lrelease translations/md3_en.ts -qm src/Md3/i18n/md3_en.qm
```

Ship `.qm` under `src/Md3/i18n/` (qrc prefix `/md3/i18n`). Rebuild Md3 after adding/updating `.qm`.

## Coverage check

```powershell
python scripts/checks/check_qstr_coverage.py --json scripts/checks/out/i18n-scan.json
```

Flags hardcoded `text:` / `title:` / … string literals that are not wrapped in `qsTr`.

## Gallery

- **Accessibility** page: language segmented control (`Md3I18n`)
- **Theme** page: RTL preview (`LayoutMirroring`) — layout direction, not translation

## App integration tips

1. Call `Md3I18n.loadLanguage(...)` early after `QQmlApplicationEngine` load, or bind from settings.
2. Persist `perf`/`ui/language` in `Md3AppSettings` if desired.
3. Keep **source language English** in library QML; Chinese via `zh_CN` catalog.
