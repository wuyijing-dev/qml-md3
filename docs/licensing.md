# Licensing (Qt-style dual license)

QML MD3 uses a **dual-licensing** model similar to Qt:

| Option | When to choose | Document |
|--------|----------------|----------|
| **LGPL-3.0** | Open source / you can meet LGPL library obligations | [`LICENSES/LGPL-3.0-only.txt`](https://github.com/wuyijing-dev/qml-md3/blob/main/LICENSES/LGPL-3.0-only.txt) |
| **Commercial** | Proprietary without LGPL obligations; **support**; **vendor certification** | [`LICENSES/Commercial.md`](https://github.com/wuyijing-dev/qml-md3/blob/main/LICENSES/Commercial.md) |

Pick **one** model per product. See root [`LICENSE`](https://github.com/wuyijing-dev/qml-md3/blob/main/LICENSE).

## Selling certification later

Commercial terms reserve a **certification** track (Integrator / Desktop Shell / OEM).
The open-source LGPL grant does **not** include the right to use certification marks.
Implement certification audits against:

- [Release checklist](getting-started/release-checklist.md)
- [A11y spot-check](topics/a11y-spotcheck.md)
- [API stability](getting-started/api-stability.md)

## MIT history note

Tagged builds **before** the dual-license change were offered under MIT. Those
historical artifacts remain under the license shipped with that tag. **Current
`main` and new releases** use LGPL-3.0 / Commercial as above.
