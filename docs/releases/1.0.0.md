# QML_MD3 1.0.0

`1.0.0` is the first stable desktop-focused release of the `Md3` QML component library.

## Highlights

- Stable `Md3ApplicationWindow` shell with navigation, tool bar, status bar, and desktop window integration points.
- Enterprise-oriented `Md3DataTable` upgrades including frozen columns, filtering, custom cell delegates, keyboard navigation, density options, and server pagination hooks.
- Stronger desktop workflow components: `Md3TreeView`, `Md3PathField`, `Md3KeySequenceField`, `Md3FileDropZone`, and `Md3VirtualList`.
- Library-level GitHub release support through `Md3ReleaseUpdater`, including metadata lookup, ZIP download, progress reporting, and extraction helpers.
- Updated Gallery coverage and API documentation for the stabilized component surface.
