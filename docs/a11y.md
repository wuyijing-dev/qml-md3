# Accessibility, RTL, text scale

## Keyboard & focus
- Interactive controls set `activeFocusOnTab`
- Activate with Space / Enter where applicable
- `Md3FocusRing` uses `colorScheme.secondary` (M3 secondary focus indicator)

## Accessible roles
- Buttons / FAB / chips: `Accessible.Button`
- Checkbox / switch: checkable + `onToggleAction`
- Radio: `Accessible.RadioButton`
- Slider: increase/decrease actions
- List tiles: `Accessible.ListItem`

Prefer setting `accessibleName` on icon-only controls.

## Contrast
- Disabled content: `colorOnSurface` @ 0.38
- Disabled containers: `colorOnSurface` @ 0.12
- Pairings follow ColorScheme roles (primary/colorOnPrimary, etc.)

## RTL
- Prefer anchors / Layouts over hard-coded left/right where possible
- Enable with `LayoutMirroring.enabled: true` at window or page scope for audits
- Gallery Theme page can be mirrored for spot checks

## Text scale
- `Md3Theme.textScale` multiplies typography via `Md3Theme.scaled(px)`
- Controls that call `scaled()` on label sizes should reflow; verify at 100% / 125% / 150% on Theme page

## High contrast
- `Md3Theme.highContrast` flag reserved for stronger outline/state overrides
