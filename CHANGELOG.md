# Changelog

## 1.0.0

First stable desktop-focused release of the `Md3` QML component library.

- Expanded core desktop surfaces with `Md3ApplicationWindow`, `Md3StatusBar`, and richer window integration points.
- Upgraded `Md3DataTable` with frozen columns, filtering, custom delegates, keyboard navigation, pagination hooks, and denser desktop behavior.
- Upgraded `Md3TreeView` and `Md3PathField` for practical desktop workflows including search, lazy loading, validation, recent paths, and drag/drop.
- Added desktop-specific controls that are hard to compose consistently from raw Qt primitives: `Md3KeySequenceField`, `Md3FileDropZone`, and `Md3VirtualList`.
- Added `Md3ReleaseUpdater` as a reusable library-level GitHub release client with metadata lookup, ZIP download, progress, and extract helpers.
- Refreshed Gallery demos and API docs to reflect the stabilized 1.0.0 component surface.
